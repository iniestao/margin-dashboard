# 📊 A股资金监控看板

基于**融资融券**、**ETF 份额/金额**与**资金流向**数据的 A 股资金面监控看板，三 Tab 设计，数据每日自动更新。

🔗 **在线预览**：https://marginflow.streamlit.app

- **Tab 1 · A股指数融资额**：全市场融资概览、指数成分股融资变化排行、历史趋势、成分股下钻
- **Tab 2 · ETF份额监控**：国家队（中央汇金系）持仓 ETF 的份额/金额监控（可切换口径），跟踪"类平准基金"资金动向
- **Tab 3 · 资金流向**：指数成分股主力净流入排行与历史趋势（当日/5日/20日），洞察资金进出方向

## 📚 数据源

| 数据 | 来源 | 说明 |
|---|---|---|
| 融资融券（沪） | 上交所官网 API（`query.sse.com.cn`） | 官方一手 |
| 融资融券（深） | 深交所官网（akshare 封装） | 官方一手 |
| ETF 份额（沪） | 上交所基金规模接口（`fund_etf_scale_sse`） | 每日公布 |
| ETF 份额（深） | 深交所基金规模报表（`fund_scale_daily_szse`） | 每日公布 |
| ETF 单位净值 | 天天基金网（fund.eastmoney.com） | 金额口径 = 份额 × 净值 |
| 个股资金流向 | 东方财富资金流向（data.eastmoney.com/zjlx） | 主力/超大/大/中/小单净流入 |
| 指数权重 | 本地 CSV（`指数权重/` 目录） | 需自行维护 |

> 资金流向为东方财富基于单笔成交金额分档推算的行业通用口径：超大单 ≥100万/50万股、大单 20-100万、中单 4-20万、小单 <4万。

## 🚀 快速开始（本地运行）

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 准备指数权重文件（放入 指数权重/ 目录）
#    格式示例 000300.SH_20260729.csv：
#    日期,成分代码,成分名称,权重(%)
#    2026-06-30,300308.SZ,中际旭创,5.008

# 3. 一键运行：自动增量拉取数据 → 聚合 → 启动看板
python run.py
# 浏览器打开 http://localhost:8501
```

## ☁️ 云端部署（免费方案）

1. 将代码推送到 GitHub 仓库
2. 在 [share.streamlit.io](https://share.streamlit.io) 部署：选择仓库 → 分支 `main` → 主文件 `app.py`
3. **GitHub Actions 每天北京时间 2:10 / 7:55 自动更新数据**（融资 + ETF 份额/净值 + 资金流向）
   - 首次部署后需在 Actions 页面手动触发一次「每日数据更新」生成历史数据
   - 之后每天自动运行，无需人工干预

## 🔄 数据更新机制

- **增量拉取**：只补缺失的交易日，重复运行无额外开销
- **双所完整性校验**：沪深两所数据都成功才保存缓存；单边缺失不保存、自动重试
- **资金流向历史回补**：首次运行自动拉取过去 100 个交易日的成分股资金流向，之后每日快照增量
- **数据时效**：
  - 融资融券：T 日盘后 17:30 起公布
  - ETF 份额：T 日清算后公布、T+1 早间确认；净值 T 日当晚公布
  - 资金流向：T 日收盘后快照，次日凌晨拉取即最新
