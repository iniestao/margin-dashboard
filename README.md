# A股资金监控看板

基于**融资融券**与 **ETF 份额**数据的 A 股资金面监控看板，双 Tab 设计，数据全部来自**沪深交易所官方公开接口**，每日自动更新。

- **Tab 1 · A股指数融资额**：全市场融资概览、指数成分股融资变化排行、历史趋势、成分股下钻
- **Tab 2 · ETF份额监控**：国家队（中央汇金系）持仓 ETF 的份额变化监控，跟踪"类平准基金"资金动向

## 功能特性

### Tab 1 · A股指数融资额
- 全市场融资概览：融资余额（万亿/亿自适应）、较 5/15/30 日前变化、最新融资买入额
- 指数融资变化排行（5/15/30 日可切换，增幅/降幅 TOP5 卡片）
- 历史趋势：多指数对比、归一化（起点=100）、余额+买入双轴
- 成分股下钻：单指数成分股的融资余额、当日买入、5/15/30 日变化与累计买入

### Tab 2 · ETF份额监控
- 国家队持仓池：**中央汇金系 2025 年报披露的 24 只宽基 ETF**（沪深300/上证50/中证500/创业板/科创50/中证1000 等）
- 池总量指标：国家队 ETF 总份额、当日净变化、较 5/20/60 日前变化
- 池内明细：每只 ETF 最新份额与 1/5/20/60 日**绝对份额变化（亿份）**
- 份额变化曲线（默认份额前 10 大，归一化对比）
- 全市场 ETF 份额变化排行（1/5/20 日，供发现参考）

## 数据源

| 数据 | 来源 | 说明 |
|---|---|---|
| 融资融券（沪） | 上交所官网 API（`query.sse.com.cn`） | 官方一手 |
| 融资融券（深） | 深交所官网（akshare 封装） | 官方一手 |
| ETF 份额（沪） | 上交所基金规模接口（`fund_etf_scale_sse`） | 每日公布 |
| ETF 份额（深） | 深交所基金规模报表（`fund_scale_daily_szse`） | 每日公布 |
| 指数权重 | 本地 CSV（`指数权重/` 目录） | 需自行维护 |

## 技术栈

- **Streamlit** — 界面
- **akshare / requests** — 数据获取
- **pandas / pyarrow** — 数据处理与缓存（parquet）
- **plotly** — 图表
- **GitHub Actions** — 每日自动更新

## 快速开始（本地运行）

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 准备指数权重文件（放入 指数权重/ 目录）
#    格式示例 000300.SH_20260729.csv：
#    日期,成分代码,成分名称,权重(%)
#    2026-06-30,300308.SZ,中际旭创,5.008

# 3. 一键运行：自动增量拉取数据 → 聚合 → 启动看板
python run.py
# 浏览器打开 http://localhost:8501
```

## 云端部署（免费方案）

1. 将代码推送到 GitHub 仓库
2. 在 [share.streamlit.io](https://share.streamlit.io) 部署：选择仓库 → 分支 `main` → 主文件 `app.py`
3. **GitHub Actions 每天北京时间 8:55 自动更新数据**（融资 + ETF 份额）
   - 首次部署后需在 Actions 页面手动触发一次「每日数据更新」生成历史数据
   - 之后每天自动运行，无需人工干预

## 数据更新机制

- **增量拉取**：只补缺失的交易日，重复运行无额外开销
- **双所完整性校验**：沪深两所数据都成功才保存缓存；单边缺失不保存、自动重试
- **数据时效**：
  - 融资融券：T 日盘后 17:30 起公布
  - ETF 份额：T 日清算后公布、T+1 早间确认
  - 每日 8:55 拉取时即最新（上一交易日数据）

## 项目结构

```
├── app.py              # Streamlit 看板（双 Tab）
├── run.py              # 本地一键入口（拉数据→聚合→启动）
├── cloud_update.py     # 云端数据更新脚本（GitHub Actions 调用）
├── etf_fetcher.py      # ETF 份额增量拉取
├── data_fetcher.py     # 融资融券增量拉取
├── aggregator.py       # 指数成分股聚合
├── index_loader.py     # 指数权重加载
├── config.py           # 全局配置
├── requirements.txt
├── 指数权重/            # 指数成分股权重 CSV
├── data/               # 数据缓存（自动生成）
└── .github/workflows/  # Actions 每日更新任务
```
